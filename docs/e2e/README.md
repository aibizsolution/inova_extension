# E2E 문서 구조

실제 Chrome E2E 검증 문서는 두 층으로 관리한다.

- `docs/e2e-browser-workflow.md`: PR 기준선, 공통 준비, 배포 전 운영 게이트, 전체 회귀 순서.
- `docs/e2e/features/*.md`: 기능별 실제 버튼/탭/권한/DB 확인 항목.

기능 추가나 사용자 흐름 변경이 있는 PR은 해당 기능별 E2E 문서를 PR 안에서 같이 갱신한다. 상용 배포나 `release:build`를 먼저 끝낸 뒤 문서를 맞추면 배포 직후 실제 Chrome 풀 테스트가 낡은 기준으로 수행될 수 있으므로, 문서 갱신은 배포 전 검증 준비 단계에 끝내는 것을 원칙으로 한다.

마지막 반영 PR 번호와 전체 회귀 기준은 `docs/e2e-browser-workflow.md`에만 둔다. 기능별 문서는 해당 기능의 최신 버튼, 탭, 상태, DB 확인법을 관리하고 PR 번호 이력은 누적하지 않는다.
